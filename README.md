# 🚀 منصة أبو العز العمري - Enterprise Agency Platform

منصة برمجية متكاملة ومؤمنة بالكامل لاستقبال طلبات تصميم وتطوير المواقع، إدارة الشكاوى، تذاكر الدعم الفني، وتقييمات العملاء، مع لوحة إشراف مركزية محمية بطبقة وصول معقدة وخزنة تشفير رقمية.

## 👑 الإدارة والتطوير
* **الجهة المطورة:** إدارة وتطوير أبو العز العمري
* **الإصدار:** 2.5.0 (Enterprise Production Grade)

---

## 🛠️ التقنيات المستخدمة (Tech Stack)
* **Backend:** Node.js, Express.js
* **Database:** MongoDB & Mongoose Schemas
* **Security & Auth:** JWT, BcryptJS, Helmet, Rate Limiting, Complex Cryptographic Vault Layer
* **Frontend:** Modern Responsive HTML5, CSS3 (Dark UI Theme)

---

## 📦 هيكل ملفات المشروع الكامل
1. `package.json` - إدارة الحزم والاعتمادات البرمجية.
2. `server.js` - النواة البرمجية الرئيسية ومسارات الـ API.
3. `securityLayer.js` - نظام التشفير وطبقة الوصول المعقدة للوحة الإدارة.
4. `style.css` - ملف التصميم والأنماط الموحد للمنصة.
5. `index.html` - واجهة استقبال العملاء، الطلبات، والشكاوى.
6. `admin.html` - لوحة التحكم المخفية والسرية للمشرفين.
7. `.env` - متغيرات البيئة وإعدادات الخادم الآمنة.
8. `.gitignore` - حماية المستودع واستثناء الملفات المحلية.
9. `README.md` - وثائق المشروع الرسمية.
